# Open Bar Drink Menu

A single-page drink list that works on GitHub Pages with no build step.

## Deploy (about 3 minutes)

1. Sign in at github.com (turn on two-factor authentication under Settings > Password and authentication).
2. Click **New repository**. Name it anything (for a URL of `yourname.github.io`, name it exactly `yourname.github.io`). Set it to **Public**.
3. Click **Add file > Upload files** and drag in `index.html` (and this README if you like). Commit.
4. Go to **Settings > Pages**. Under "Build and deployment," set Source to **Deploy from a branch**, choose branch **main** and folder **/ (root)**, then Save.
5. Wait a minute or two. Your site appears at `https://yourname.github.io/` (or `https://yourname.github.io/repo-name/` for other repo names).

## Editing the menu

Open `index.html` on GitHub, click the pencil icon, and change the drink names and descriptions. Each drink is one `<div class="drink">` block. Copy one to add a drink, delete one to remove it. Commit and the site updates in a minute or so.

## Tips

- Make a QR code of your site URL (free generators work) and tape it to the bar.
- Don't put personal info, passwords, or keys in a public repo.
